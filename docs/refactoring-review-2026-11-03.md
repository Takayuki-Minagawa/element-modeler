要素一覧での種類・階・断面・ID検索と線材の一括選択はすでに存在するため、同種の検索画面を増やす優先度は低い。選択反転・接続要素選択は候補になるが、表示フィルタや階の扱いを別途定義する必要がある。今回は線材の範囲選択を改善する。

## 交差選択の使い方

1. 平面入力で「要素」ツールを選び、空白からドラッグする。
2. 左→右なら青い実線枠になり、両端が枠内にある線材を選ぶ。
3. 右→左なら緑の破線枠になり、枠に触れる・横切る線材も選ぶ。両端が枠の外でも交差していれば対象になる。
4. Shiftを押しながら開始すると既存の選択へ追加する。Escでドラッグ中の範囲選択を中止する。

境界上の線材や平面上で点になる柱も対象になる。判定は平面の節点座標を使う。非表示・他レイヤー選択ロックの条件は既存の判定を利用する。対象は線材で、面材・荷重・支点は従来のクリック選択を使う。選択操作でモデル内容やUndo/Redoの履歴は変わらない。

## 節点マージの互換性

従来はID順に節点を調べ、まだ統合されていない節点から許容差内にある後続節点を統合していた。この順序と距離判定を維持したまま、近傍候補の絞り込みを追加する。

例えば A–B と B–C が許容差内でも、A–C が許容差外なら、AにBを統合した後のCは残る。連鎖的にすべて統合する処理には変更しない。節点を実際に統合した場合のみモデルを更新し、既存のコマンド・履歴処理を使う。

## 追補: 線材の一括選択（2026-11-14）

上記で候補とした選択反転・接続要素選択を、全選択と合わせて追加した。

| 一次資料 | 確認内容 | このリポジトリへの適用 |
| --- | --- | --- |
| [QCAD User Reference Manual](https://www.ribbonsoft.com/doc/qcad/latest/reference/en/toc.html) | Select All / Invert Selection / Select Contour（接続要素の選択）を選択メニューに並べる構成 | 「編集」メニューに「線材の選択」として3コマンドを追加。上流コードの転用は行わない |
| [QCAD Tutorial: Entity Selection](https://www.qcad.org/en/tutorial-1-8-entity-selection) | 接続要素を連続してたどる選択 | 共有節点からの幅優先探索で線材をたどる |

定義した扱い:

- 対象は線材のみ（複数選択が線材だけのため）。表示フィルタ・他レイヤー選択ロックは既存の `isMemberSelectable` を使い、対象外の線材は結果にも経路にも含めない。
- 平面節点は階をまたいで共有されるため、接続は「節点ID + 端部高さ」で判定する。端部高さは解析JSON出力と同じ規則（柱・鉛直ブレースは下端/上端レベル、明示3D座標はstartZ/endZ、X形ブレースは両対角）。
- 反転は「選択可能な線材のうち未選択のもの」。面材などが選択中なら全線材を選ぶ。
- `Ctrl+A` / `⌘A` は平面表示でのみ全選択。入力欄・モーダル表示中・3D表示中はブラウザ既定動作のまま。
- 選択だけを変更し、モデル・revision・Undo/Redo履歴は変えない。
